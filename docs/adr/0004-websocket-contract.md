# ADR 0004: Same-origin WebSocket transport and event contract

Status: accepted for Slice 2.

Use `/api/ws` through the existing Next.js external rewrite, which forwards Upgrade requests. The backend accepts only the configured `FRONTEND_URL` Origin and the existing access cookie, verifying issuer, audience, expiration and the database session. No tokens in URLs, browser storage or socket frames. This slice runs one Uvicorn worker.

Clients send `subscribe` (workspace, optional channel, last_seq), `unsubscribe`, `typing.start`, `typing.stop`, and `ping`. Subscriptions are checked against current workspace membership and private channel membership each time. Workspace subscriptions receive only visible channel metadata and per-user unread counts. Channel subscriptions receive ordered durable events and ephemeral presence/typing. Removed access returns the same generic error as nonexistent IDs; a revoked/expired session closes with code 4001. Reconnect obtains fresh cookies through the existing API refresh flow.

The shared envelope is `{type, workspace_id, channel_id, seq, data}`. `seq` is null for metadata snapshots, presence, typing and errors. Durable events use a positive channel-local integer. Event names are `message.created`, `message.updated`, `message.deleted`, `thread.reply_created`, `channel.created`, `channel.updated`, `channel.archived`, `member.joined`, `member.left`, `presence.update`, `typing.start`, `typing.stop`, `read.updated`, `error`. Message events contain `data.message`; reply creation also contains `data.thread_root` with the authoritative reply count; workspace metadata contains `data.channel`; membership/typing events contain `user_id`; presence contains `user_ids`; read events contain `user_id` and `last_read_seq`; errors contain `code` and a safe `message`. Membership events describe channel membership, not the workspace invitation workflow.

`backend/app/channels/schemas.py` owns command/envelope validation and event names. `backend/.venv/bin/python infra/export_events.py` generates `docs/channel-events.schema.json` and `frontend/src/lib/events.generated.ts`. `--check` detects drift; frontend payload types are in `channels.ts`. Pydantic validates the message, attachment, channel and ephemeral payload fields. The same JSON schema generates the frontend payload types, so CI detects drift.

Browser pings every 15 seconds; configurable server idle timeout defaults to 60 seconds. Commands are limited to 120/minute, frames to 8 KiB, connections to 5/user and 30/IP. The gateway also bounds subscription count. Typing expires after five seconds without a refresh, presence disappears on disconnect, and both are filtered against current membership/session state. Process-local rates/presence are deliberately not suitable for multiple workers. Behind the current local Next proxy, IP limits apply to the proxy address; a production trusted-proxy configuration needs its own review.
