# ADR 0016: Workspace provider chain and explicit data sharing

Accepted for Slice 4. Default workspace chain is Groq then Gemini. Agent is off by default at workspace level; public channels are eligible when enabled and private channels start off. Owner/Admin manage enablement, per-channel access and limits. Only an Owner can add DeepSeek/OpenAI to the workspace chain. The settings UI warns that each enabled provider receives workspace data. Removing opt-in is allowed for an Admin. Try AI remains a separate Admin-only synthetic trial with its existing provider selection and metadata storage.

Models remain backend environment settings, sharing keys, fixed destinations, clients, timeout configuration and safe failure classification with trial adapters. Startup checks configured model IDs using read-only model metadata calls, with available/not_configured/error status visible in settings. Missing credentials never silently choose a fake. A marked test/development-only AGENT_FAKE_PROVIDER option permits deterministic local/CI tests with no keys/network; production must leave it false. A model metadata check is not proof generation/quota/tool protocol works; optional live script validates synthetic structured tool calling separately.

Automatic fallback covers safe provider failures, rate limits, invalid/empty output and per-call timeouts within the overall deadline. Every attempted provider switch is audited. The next provider receives only the same authorized question/tool results, never prior raw provider outputs. No prompts/answers/upstream exception bodies enter run metadata or logs. Metadata token totals include successful parsed turns; a provider that fails without usage data cannot be accurately billed from these counters.
